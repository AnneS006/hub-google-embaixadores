# 🐙 GitHub Student Developer Pack

O "Santo Graal" das ferramentas para estudantes de tecnologia. O GitHub empacota dezenas de licenças e créditos gratuitos em uma única verificação de estudante.

> Ofertas conferidas em setembro de 2026 na [página oficial do Pack](https://education.github.com/pack). Os parceiros mudam com frequência: confira lá antes de contar com um benefício específico.

## 🟢 Nível 1 — O que é e quem pode pedir

### Requisitos (segundo a documentação do GitHub)

- Ter **pelo menos 13 anos**.
- Estar **matriculado** em um curso que dá diploma (ensino médio, técnico, graduação…).
- Ter uma **conta pessoal** no GitHub.
- Enviar um **comprovante de matrícula atual**: carteirinha com data de validade, grade de horários, histórico ou declaração de matrícula.

Se a sua instituição fornece e-mail acadêmico, use-o — ajuda (e pode ser exigido) na verificação.

### Principais benefícios

| Categoria | Benefício | O que você ganha |
| --- | --- | --- |
| GitHub | **GitHub Pro** | Grátis enquanto você for estudante |
| GitHub | **Copilot Student** | Autocompletar ilimitado e uma cota de créditos de IA para chat e agente — veja [GitHub Copilot](github-copilot.md) |
| GitHub | **Codespaces** | Cota do nível Pro: 180 horas de computação e 20 GB de armazenamento por mês |
| Nuvem | **Microsoft Azure** (18+) | US$ 100 em créditos + mais de 25 serviços gratuitos |
| Nuvem | **Heroku** | US$ 13 de crédito por mês durante 24 meses |
| Banco de dados | **MongoDB Atlas** | US$ 50 em créditos + MongoDB University |
| IDEs | **JetBrains** | Licença de todas as IDEs (IntelliJ, PyCharm, WebStorm…), renovada todo ano |
| Domínios | **Namecheap** | Domínio `.me` por 1 ano + certificado SSL por 1 ano |
| Domínios | **.TECH** | Um domínio `.tech` por 1 ano |
| Cursos | **Frontend Masters** | 6 meses de acesso a todos os cursos |
| Cursos | **DataCamp** | 3 meses de acesso |
| Cursos | **Educative** | 6 meses de acesso a mais de 70 cursos |
| Git | **GitKraken** | 6 meses grátis do plano Pro |

O Pack também traz ofertas de Notion, Microsoft 365, 1Password, Sentry, Datadog, Stripe, Appwrite, Clerk e dezenas de outros parceiros.

## 🟡 Nível 2 — Fazendo a verificação

1. **Prepare a conta:** coloque seu nome completo no perfil do GitHub e adicione o e-mail acadêmico em **Settings → Emails** (confirme pelo link que chega na caixa de entrada).
2. Acesse [education.github.com/pack](https://education.github.com/pack) e clique para se inscrever como estudante (ou vá direto em **Settings → Education benefits**).
3. Escolha sua instituição e o e-mail acadêmico.
4. **Envie o comprovante:** tire a foto pelo próprio site, com boa luz, mostrando **seu nome, o nome da instituição e uma data atual** (validade ou semestre).
5. Aguarde a análise. Depois da aprovação, os benefícios do GitHub (Pro, Copilot, Codespaces) podem levar alguns dias para aparecer.

**Motivos comuns de recusa:**

- Documento sem data ou com data vencida.
- Nome no documento diferente do nome no perfil do GitHub.
- Foto cortada, desfocada ou de tela de computador.
- Localização muito diferente da cidade da instituição (desative VPN durante o pedido).

> **⚠️ Atenção:** a aprovação pode levar alguns dias. Faça a sua verificação muito antes do dia do seu hackathon começar!

## 🔴 Nível 3 — Tirando o máximo do Pack

### Monte uma stack de portfólio que custa zero

| Parte | Benefício |
| --- | --- |
| Domínio `seunome.me` | Namecheap (1 ano) |
| Site do portfólio | GitHub Pages — veja [Hospedagem gratuita](../cloud-e-baas/hospedagem-gratuita.md) |
| API de um projeto | Heroku (crédito mensal) ou Azure |
| Banco | MongoDB Atlas (créditos) ou um BaaS gratuito como o [Supabase](../cloud-e-baas/supabase.md) |
| Monitoramento de erros | Sentry ou Honeybadger |
| Ambiente de desenvolvimento | Codespaces, acessível de qualquer computador do laboratório |

### Cuidados

- **Créditos de nuvem acabam.** Coloque alertas de orçamento no Azure e saiba a data de expiração de cada crédito.
- **Domínios renovam a preço cheio** depois do primeiro ano. Desative a renovação automática se não for usar.
- **A verificação vence.** O status de estudante precisa ser reconfirmado periodicamente; quando você se formar, os benefícios acabam.
- **Ative só o que vai usar.** Ofertas com prazo (6 meses, 3 meses) começam a contar na ativação.
