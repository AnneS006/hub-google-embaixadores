# ☁️ Cloud e BaaS (Backend as a Service)

Para quem desenvolve aplicações web (como projetos em Next.js e TypeScript), ter um banco de dados em tempo real e autenticação sem precisar configurar servidores do zero é essencial, especialmente em hackathons.

## 🔥 Firebase
O Firebase oferece um nível gratuito (Spark Plan) extremamente generoso, ideal para estudantes validarem MVPs.
- **O que inclui gratuitamente:** Autenticação (Authentication), Banco de Dados NoSQL (Firestore), Hospedagem (Hosting) e Storage.
- **Como acessar:** Basta ter uma conta Google. Não exige verificação universitária para o plano Spark.
- **Link oficial:** [Firebase Console](https://console.firebase.google.com/)

## ⚡ Supabase
Uma das melhores alternativas open-source ao Firebase, rodando um banco de dados relacional (PostgreSQL).
- **O que inclui gratuitamente:** Banco de dados PostgreSQL (até 500MB), Autenticação, Storage (1GB) e Edge Functions. É uma base sólida para integrar com aplicações frontend modernas.
- **Como acessar:** Acesso imediato pelo tier gratuito (Free Plan).
- **Link oficial:** [Supabase](https://supabase.com/)

> **💡 Dica da Comunidade:** Se o seu projeto acadêmico precisar escalar e os limites gratuitos forem atingidos, o GitHub Student Developer Pack frequentemente oferece créditos ou acessos especiais a provedores de nuvem que podem ser integrados a essas arquiteturas.
