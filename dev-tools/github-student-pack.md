# 🐙 GitHub Student Developer Pack

O "Santo Graal" das ferramentas para estudantes de tecnologia. O GitHub empacota dezenas de licenças gratuitas em uma única verificação.

## 🎁 O que inclui (Principais benefícios):
- **GitHub Copilot:** Gratuito (normalmente pago mensalmente) para autocompletar código com IA.
- **GitHub Pro:** Repositórios privados com recursos avançados.
- **Namecheap / .ME:** Um domínio gratuito por 1 ano + certificado SSL (ideal para seu portfólio).
- **DigitalOcean:** $200 em créditos de plataforma para hospedar suas aplicações.
- **JetBrains:** Acesso a todas as IDEs profissionais (IntelliJ, WebStorm, PyCharm).

## 🔐 Como acessar:
1. Acesse o site oficial: [GitHub Education](https://education.github.com/pack).
2. Você precisará vincular o seu e-mail institucional (ex: `@aluno.faculdade.edu.br`) à sua conta do GitHub.
3. Pode ser necessário enviar uma foto do comprovante de matrícula atualizado ou carteirinha de estudante com data de validade.

> **⚠️ Atenção:** A aprovação pode levar alguns dias. Faça a sua verificação muito antes do dia do seu hackathon começar!
